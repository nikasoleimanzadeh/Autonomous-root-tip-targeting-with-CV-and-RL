# Controller Experiment Records

This folder preserves historical evaluation arrays and TensorBoard outputs for PPO experiments. They help document how policies changed during development but are not themselves an entry point to the project.

For a public portfolio, retain a compact selection of non-sensitive summary metrics and comparison plots, not every intermediate run artifact. Match each displayed result to its configuration, seed, and evaluation procedure. Do not upload restricted or externally trained checkpoints without checking redistribution rules.
